# CRYSTAL / OSINT

**Public research portfolio · Responsible open-source intelligence**

Crystal OSINT Hub is the public home for an independent OSINT research portfolio. It presents research disciplines, verification practices, and principles without disclosing investigations or distributing private tools.

## The focus

Public-source research · Social platform context · Digital preservation · Source verification · Web and domain research · Responsible reporting

## Private by design

This repository is **website-only**. It contains no internal software, operational tooling, Discord/VRChat integrations, case evidence, suspect identities, personal records, or investigative methods that must remain confidential. Nothing on the site should be taken as an allegation against any person.
